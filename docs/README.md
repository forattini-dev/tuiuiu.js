# Tuiuiu documentation

Tuiuiu 2 builds terminal interfaces from keyed function components, signals,
semantic interaction, and a deterministic renderer.

Start with:

- [Installation](/getting-started/installation.md)
- [Quick start](/getting-started/quick-start.md)
- [Import map](/core/imports.md)
- [Interaction runtime](/core/interaction-runtime.md)
- [Migrating from 1.x](/migration/2.0.md)

The root package is intentionally compact. Import the complete visual catalog
from `tuiuiu.js/ui`, app lifecycle and hooks from `tuiuiu.js/app`, low-level
interaction contracts from `tuiuiu.js/interaction`, and rendering mechanics
from `tuiuiu.js/core`.
